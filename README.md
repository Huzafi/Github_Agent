# GitHub Agent 🐙

**GitHub Agent** is an AI-powered automation agent that helps you manage your GitHub repositories effortlessly through simple chat commands.

---

## Features

- **Create Repositories:** Instantly create new GitHub repositories via chat.  
- **List Repositories:** Get a list of all your repositories in seconds.  
- **Delete Repositories:** Remove repositories safely without opening GitHub manually.  
- **Seamless Automation:** Eliminates repetitive tasks, saving you time and effort.

---

## Technologies Used

- **Python**  
- **OpenAI Agents SDK**  
- **GitHub API**
- **Gemini API**
